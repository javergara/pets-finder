## 2026-08-15 — Fix de entorno: los 147 tests de web fallaban en Node 25 (bloqueaba el módulo de adopción)

- Síntoma: `bash init.sh` en rojo sobre `develop` limpio, con los 23 archivos de test de web fallando en masa con `TypeError: localStorage.getItem is not a function` (API en verde, 174/174). Causa raíz: Node 22.4+ expone un `localStorage` nativo (Web Storage API, ya sin flag en Node 25.9) que sin `--localstorage-file` es un objeto vacío sin métodos; el entorno jsdom de Vitest no pisa los globals que Node ya define, así que ese objeto le gana al `Storage` real de jsdom (verificado: jsdom standalone sí devuelve un `Storage` con `getItem`, y `--no-experimental-webstorage` hace desaparecer el global roto).
- Fix en `src/web/src/test/setup.ts`: se instala un `Storage` en memoria **solo si** el global está roto — en Node 24, en CI y en cualquier entorno sano es un no-op y sigue mandando jsdom. Se descartó `NODE_OPTIONS=--no-experimental-webstorage` en el script de test porque un colaborador con Node < 22.4 recibiría "bad option". +1 test de guarda en `lib/session.test.ts` que falla en una línea si la reparación se cae, en vez de dejar 147 rojos con un TypeError críptico.
- `bash init.sh` en verde tras el fix: **174 tests de API + 148 de web**. Esta es la línea base del módulo de adopción.
