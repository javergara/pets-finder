# Adopta

App de adopción de mascotas con mecánica de descubrimiento tipo "swipe", enfocada en la compatibilidad real entre el estilo de vida del adoptante y las necesidades de la mascota. Mercado inicial: Colombia (Bogotá), es-CO.

Proyecto en construcción siguiendo un flujo de *harness engineering* — ver [`AGENTS.md`](AGENTS.md) para el mapa de reglas y [`CLAUDE.md`](CLAUDE.md) para retomar el trabajo (se crea al cierre del proyecto).

## Estado

En fase de bootstrap. Ver [`progress/current.md`](progress/current.md) para el estado vivo y [`feature_list.json`](feature_list.json) para el alcance.
